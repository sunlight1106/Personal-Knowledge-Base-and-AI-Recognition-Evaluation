- 实际点击 Kimi 进入对应设置；验证水滴位移随时间变化、减少动态效果时停止；检查首页与背单词的桌面截图。

## 范围

这是边界、权限组合和主要操作流程的系统测试，不是所有输入与所有操作顺序的数学穷举。未使用个人 API 密钥调用付费模型；外部供应商的可用模型和额度由用户自行检查。本轮没有覆盖 ARM、macOS、Linux 图形桌面启动器或真实公网多人容量测试。

安装包不包含个人配置、数据库、上传文件或浏览器登录状态。镜像、程序包均使用 SHA-256 校验。首次下载时间受网络与病毒库更新影响；重复启动不会重建或重新下载已有镜像。
