# 0.12 测试版

这次新增首页词汇量自测，提供「勾选认识的词」「英译汉」「汉译英」三种模式。完成后查看各词频层级表现和参考范围，按学习方向推荐词书，也可回看不熟悉的词、下载结果摘要。

## 从哪里开始

首页的「测试词汇量」无需登录。工作台和背单词页面也有入口。第一次可以选择勾选模式；只勾选能说出至少一个词义的词，不确定就留空。

结果是帮助选书的教学参考，尚未经过大规模人群标定，不代表英语总词汇量、CEFR 或考试分数。英译汉采用四选一释义题；汉译英提供首字母和长度提示，因此三种成绩要分别看待。[详细说明](VOCABULARY-ASSESSMENT.md)

答案仅在当前页面处理，不调用 AI，不上传，不改变学习进度。离开或刷新会清空答案。推荐词书登录后才能学习，并保留原有权限限制。

## 安装和更新

1. 安装并启动 Docker Desktop，使用 Linux x64 容器。
2. 在 [v0.12 发布页](https://github.com/sunlight1106/Personal-Knowledge-Base-and-AI-Recognition-Evaluation/releases/tag/v0.12) 下载 `0.12.exe`，或完整解压 Windows 包后运行其中的启动器。
3. 首次准备需要网络，启动器会核验配套文件并打开网站；后续启动复用现有镜像。
4. 已安装用户先做 [备份](COMPOSE_BACKUP.md)，关闭旧启动窗口，再运行新版。继续沿用 `%LOCALAPPDATA%\PKB-AI\0.1`、原配置和数据卷，不会自动搬运源码版中的账号和笔记。

本次没有新增数据库迁移。初次安装的管理员账号为 `admin`，初始密码见安装目录 `.env` 中的 `BOOTSTRAP_ADMIN_PASSWORD`；不要分享此文件。0.x 仍是测试版，发布页附 `SHA256SUMS` 供核对下载文件。
