# 学习统计、文档与离线学习

[← 使用文档](README.md)

## 看每天和累计学了多少

打开右上角「目录与账户 → 学习统计」。顶部可以继续最近的笔记、到期词汇和复习卡，下面显示累计数据、最近七天回顾和每日趋势。可以切换 7 天、30 天、90 天或一年，并下载 CSV 明细。

管理员从「用户管理 → 选择用户 → 用户学习统计」查看该用户的数据。此入口同时要求用户查看和管理统计权限，只显示数量，不展示私人笔记正文。

| 项目 | 怎么算 |
| --- | --- |
| 词汇答题 | 每次有效提交算一次，重复点击或网络重试不重复计数 |
| 学习单词 | 按单词去重，跨词书的同一个词只算一个；学习过不等于掌握 |
| 复习卡 | 每次成功提交回忆评分算一次 |
| 整理笔记 | 一篇笔记一天多次保存只算一篇；累计按笔记去重 |
| 活跃时长 | 学习页面可见且最近一分钟有操作才计时；后台、闲置和多标签页不重复累计 |

日期沿用账户的学习时区，未设置时用上海时区。历史词汇答题会在更新时导入；笔记整理与活跃时长从本功能启用后记录。时长是活跃估算，不是专注程度或真实掌握度。旧词汇备份中的汇总历史仍在背单词页面显示，不伪造成逐题记录。

## 导入 PDF 和 Word

1. 打开「学习中心 → 文档阅读」，选择「导入 PDF / Word」。
2. 上传带文字的 PDF 或 `.docx`。单份不超过 10 MB、300 页 PDF、50 万字符。
3. 左边选文档，右边按页码或段落阅读；可下载原文件，将当前片段整理成笔记。
4. 在「资料搜索与问答」选择「文档正文」，搜索文档中的词句。引用保留原文的页码或段落位置。

扫描版 PDF 可以在导入时勾选本地 OCR，完成后对照原页校对文字，详见[阅读与任务](STUDY_WORKFLOWS.md)。旧版 `.doc` 请另存为 `.docx`。上传仍须通过安全扫描，不会因为文档导入绕过检查。文档只属于导入它的账户。

## 把 AI 自测变成复习卡

在笔记编辑页选择个人模型，点击「生成自测」，核对发送内容后生成。模型按要求返回题目时，结果下方会出现可编辑的问题与答案。先核对，再点击「保存这些复习卡」。重复点击不会创建重复卡片。

之后打开「学习中心 → 复习卡」，先回忆，再查看答案并评分。词汇和卡片使用 FSRS 调整后续间隔；旧进度保留，从下一次复习起更新记忆状态。词汇的「学习设置」可调整目标记忆率：数值越高，通常需要更频繁地复习。新词先隔日复习。

## 断网前准备

1. 在线登录，打开「学习统计 → 准备离线笔记与词汇」。
2. 确认账户编号，设置至少 10 个字符的独立离线口令。已有空间用原口令解锁。
3. 点击「选择离线资料」，勾选笔记与词书，再点击「加密下载所选资料」。
4. 首次准备后保持联网，让浏览器缓存应用文件，再收藏 `/offline` 页面。离线能力需要 HTTPS 或本机 localhost。

每次最多选择 20 篇笔记；每份词汇包最多 100 词，优先包含到期或未学完的词。离线空间不保存登录密码、API 密钥或登录凭证，内容使用独立口令加密后存入本机浏览器。

断网后打开收藏页并解锁，可以阅读、编辑笔记和练习拼写。修改笔记后点击「保存本地修改」。不要在未保存时关页。

## 联网后同步

先登录原账户，再回离线页点击「联网同步」。

- 笔记线上版本没变：保存离线修改。
- 线上也有修改：保留两份，可导出本地内容或「另存为新笔记」，不会直接覆盖线上版本。
- 离线词汇包七天内可同步。相同日期、相同单词只计一次离线练习；线上已有新进度时保留线上进度。
- 离线练习计入答题记录和练习证据，不自动计为独立掌握，也不覆盖线上 FSRS 计划。

忘记离线口令无法解密本地副本；已经同步的线上数据不受影响。浏览器清理站点数据也会移除尚未同步的内容，因此离线副本不能替代正式备份。
