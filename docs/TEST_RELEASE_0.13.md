# 0.13 测试版

这次修正词汇自测结果：主结果显示近似词数与水平刻度，分别标明认识、理解和回忆拼写。勾选改为 40＋120 词，翻译可继续细测新题。另增加 16 本词书，内置词书从 18 本增至 34 本，涵盖通用分级、四级基础、六级衔接，以及旅行、生活、饮食、健康、人际、新闻、科学、数学、环境、文化、写作和人工智能主题。

## 使用

登录后打开「背单词 → 我的词书」，按分类或关键词找书。可先查看单词再开始学习；在不同词书中遇到同一单词，会接续这个账号已有的学习进度。

首页词汇量自测也能按生活、旅行、职场与科学方向推荐词书。近似估计和推荐不代表考试成绩或对整本专业词书的掌握。[词书目录](VOCABULARY.md) · [自测方法](VOCABULARY-ASSESSMENT.md)

## 安装与更新

从 [v0.13 发布页](https://github.com/sunlight1106/Personal-Knowledge-Base-and-AI-Recognition-Evaluation/releases/tag/v0.13) 下载 `0.13.exe`，或完整解压 Windows 包。启动 Docker Desktop（Linux x64 容器）后运行新版启动器。

更新包含 V49 词库迁移。先[备份数据](COMPOSE_BACKUP.md)，关闭旧启动器，再打开新版；升级保留原安装目录、账号、个人词书与学习进度。首次准备需要下载配套文件，后续复用本地镜像。不要用旧版启动器回退已经升级的数据库。

0.x 为测试版。发布页提供 SHA256SUMS；初次安装的管理员初始密码见安装目录 `.env` 的 BOOTSTRAP_ADMIN_PASSWORD，请勿分享此文件。
