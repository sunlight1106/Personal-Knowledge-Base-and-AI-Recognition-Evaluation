## 本轮没有添加的操作

- 解散群组保留只读历史，不等于永久擦除聊天数据。当前不提供永久清除群历史。
- 被实验、笔记或分享引用的素材不能只加一个前端删除按钮；还需要引用检查和存储清理规则，因此本轮未开放素材永久删除。
- 管理审计与用量日志没有提供任意删除入口。

新增操作均沿用服务端身份与资源权限检查。没有调用外部 AI，也不会把个人内容作为测试材料发送给他人。测试范围和结果见 [验证记录](VALIDATION.md)。
