# 0.1 测试版 · Windows

**当前下载：2026-10-17 修订 2。** 包含学习中心断线恢复修复。已经安装过 0.1 的用户，下载下面的新包并运行其中的 `0.1.exe`，即可更新已有安装，保留账号、笔记和配置。

## 下载与打开

1. 在 [v0.1 发布页](https://github.com/sunlight1106/Personal-Knowledge-Base-and-AI-Recognition-Evaluation/releases/tag/v0.1) 下载 **PKB-AI-0.1-Windows-x64.zip**。
2. 完整解压，双击 **0.1.exe**。请保留旁边的 `runtime-0.1-r2.zip`，不要在压缩包内直接运行。
3. 等启动窗口显示「平台已就绪」，浏览器会自动打开。

也可以[直接下载 0.1.exe](https://github.com/sunlight1106/Personal-Knowledge-Base-and-AI-Recognition-Evaluation/releases/download/v0.1/0.1.exe)；首次运行时它会从同一个发布页下载并校验程序文件。旧启动器不会自动变成新版，请重新下载。

需要 **Windows 10 / 11 x64、Docker Desktop（Linux 容器）和网络**。不需要另装 Java、Node.js 或 Python。建议给 Docker 分配 8 GB 内存，磁盘预留至少 12 GB。首次会下载容器镜像和文件扫描病毒库；日常启动复用本机镜像与数据，不重新编译。训练环境是可选服务，默认不下载训练镜像。

这是尚未签名的测试程序。Windows 可能显示发行者未知；请从上述发布页下载并核对 `SHA256SUMS`，不要关闭系统安全功能。

## 第一次登录

- 管理员用户名：`admin`。
- 点击启动窗口的「打开安装目录」，打开 `.env`，找到 `BOOTSTRAP_ADMIN_PASSWORD=` 后的随机密码。每次安装单独生成，不共用默认密码。
- 登录后在「设置 → 安全与登录」更改密码，再创建自己的日常账户。
- AI 功能需自行填写供应商配置；安装包不含任何人的 API 密钥。普通笔记、背单词和代码可视化不需要外部 AI。

程序目录：`%LOCALAPPDATA%\PKB-AI\0.1`。默认访问 `http://localhost:4173`；首次安装端口被占用时会选 4174–4182。以后使用已保存的端口，实际地址以启动窗口为准。

程序和镜像清单在打包时固定：应用镜像下载后检查 SHA-256，MySQL、Redis 和 ClamAV 使用固定的仓库摘要。首次启动会拉取这些依赖，病毒库仍会正常更新。

## 再次启动、停止与数据

再次双击 `0.1.exe` 即可。服务已启动时直接打开网页；服务已停止时只启动现有容器。关闭启动窗口或网页不会关闭后台服务。

需要停止时，在 Docker Desktop 停止 **pkb-personal** 项目。它与源码开发版 `robust-vision` 使用独立的数据卷，不会自动复制你已有开发版的账号、笔记或词汇进度。发布版的安装过程不会删除或覆盖开发版数据。

不要删除 Docker 数据卷或安装目录中的 `.env`。备份和迁移请看安装目录的 `docs/COMPOSE_BACKUP.md`。本次修订只更新应用，不迁移或重建数据库、文件存储。其他版本升级前先备份。

## 如果启动不成功

| 提示或现象 | 怎么处理 |
| --- | --- |
| 找不到 Docker | 安装并打开 Docker Desktop，切换到 Linux 容器，再点「重试启动」 |
| 镜像下载慢或中断 | 检查网络后重试；已完成的镜像复用，未完成的下载尝试续传 |
| 校验失败 | 重新从同一发布页下载；启动器不会导入校验不符的镜像 |
| 端口已占用 | 先停止占用该端口的程序；已安装版本不会擅自改变地址 |
| 文件上传暂时不可用 | 首次病毒库下载可能尚未完成，在 Docker Desktop 查看 clamav 状态 |
| 其他错误 | 查看安装目录 `.runtime/desktop-startup.log` 和 Docker Desktop 中对应服务的日志 |

## 本次变化

- 修订 2：修复学习中心断线后残留其他标签数据的问题，加入重新加载入口并保留表单草稿。启动器检查正在运行的程序版本，避免下载新版后仍然打开旧页面。
- 全站水滴落下、触水和多层涟漪，连续波浪；右上角波浪图标可开启或暂停，并在当前浏览器记住选择。默认跟随系统的减少动态效果偏好，也支持手动开启；离屏和后台仍暂停动画。
- 模型中心改成 Kimi、千问、DeepSeek 等供应商入口，点击进入对应配置。
- 常用入口最多固定 12 个，窗口较窄时自动收进「更多」；电脑端使用小范围淡蓝光晕的箭头光标。
- 修复短时间连续发送群消息时可能出现的顺序颠倒与残留未读，旧的已读请求不会覆盖较新的阅读进度。
- 私有笔记、背单词、群组、权限管理与代码可视化保留；代码可一键存入笔记、命名存档和导出。

这是第一个公开测试版本。已验证的测试范围与限制见仓库中的 `docs/RELEASE_0.1_VALIDATION.md`，不代表不存在未发现的问题。
