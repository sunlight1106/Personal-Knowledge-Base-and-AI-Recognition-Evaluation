# 0.11：登录保护与首次使用

本次补丁在已有权限、会话、文件安全和双重验证的基础上，加强登录入口并调整工作台引导。当前属于 0.11 待发布内容。

## 登录与请求检查

- 同一账号的用户名、身份码、已验证邮箱共用密码失败计数。15 分钟内连续失败 8 次后，停止接受该账号的新登录 5 分钟。切换 IP、普通登录、切换账号或恢复停用账号，均不能绕过计数。
- 冷却期间的重试不延长时间；冷却结束、计数窗口过期或成功登录后按规则重新计数。未知用户名不创建计数记录，避免随机用户名把数据库撑大。既有会话不因密码猜测被注销。
- 计数保存在数据库，更新前锁定对应用户，支持并发请求及多个后端实例。接口不透露账号是否存在、失败次数或是否正在冷却；错误响应与普通密码错误一致。原有按来源 IP 的限流仍然保留。
- 重复 JSON 字段、单次请求中追加第二段 JSON、重复或合并的 Authorization 凭据会被拒绝；错误信息不回显密码或请求正文。
- 修复未知用户名触发事务回滚后返回 500 的问题，改为普通认证失败。

这不是设备绑定：持有仍有效的登录令牌，就可能以该会话访问接口。发现异常设备时应撤销会话；退出或撤销后旧令牌不再有效。公开部署仍须使用 HTTPS，防止网络链路上泄露密码和令牌；参见 [公网部署](PUBLIC_DEPLOYMENT.md)。CORS、隐藏按钮或压缩前端代码不能代替后端鉴权。浏览器、插件或设备本身已被控制的情况，不在这些改动能保证解决的范围内。

临时限制也可能被他人恶意触发，因此限制只持续 5 分钟，不因受限期间的请求无限续期，不会自动封禁账号。邮箱重置、双重验证和登录设备管理继续使用原有流程；短信服务未配置时不提供虚假验证。

## 首次使用

工作台「从这里开始」会从当前账号可用的任务中推荐下一步，默认展开操作步骤，并说明成功保存后应看到的结果。可以切换目标、检查完成情况、收起或重新展开。

进度只来自服务器中本人实际保存的笔记、练习、文档和复习卡。查看帮助、点击入口不会算作完成；切换账号或调整权限后重新读取。网络失败显示重试，不伪装成全部完成。没有学习权限的账号会得到说明和个人设置入口。

新增账号安全、隐私与使用说明快捷入口。普通入门任务无需 AI 密钥；完整说明支持中英文和键盘操作。偏好只按账号存于当前浏览器，浏览器不允许保存偏好时仍能使用引导。

入门查询一次读取有效权限，按用户查到首条记录便停止，不统计所有历史记录。
