# 0.15 测试版

这次更新加入按账号保存已读状态的版本公告，处理执行记录的刷新竞争，并降低首页加载和代码回放的重复开销。

## 修改内容

- 每次更新后，登录用户会收到当前版本的更新公告。点击「查看详情」在当前页面打开完整说明；点击「已读」后立即清除该条未读提醒。
- 公告分为新增功能、体验优化、问题修复与更新后需要注意四部分，可切换中英文。说明与版本历史、GitHub 更新日志使用同一份发布记录。
- 弹出卡片约五秒收起，悬停、键盘聚焦时暂停。收起和查看详情都不等于已读，仍能从通知中心重新打开；已读状态按账号和版本保存，换浏览器也能同步。
- 首次启用这项功能显示当前版本。保存失败保留未读并允许重试，重复点击只发出一次请求；切换账号后，旧请求不能清除新账号的提醒。
- 执行记录加载期间禁用重复刷新。运行代码后会取消先前的列表请求，较晚返回的旧列表不能覆盖新记录。
- 刷新失败保留已有记录，重试成功后清除错误；离开页面时取消请求。
- 登录页与登录后的工作空间按需加载，首页不再提前下载它们的界面逻辑。
- 数组图每帧只计算一次比例；执行分布共用一个峰值。回放结果作为完整快照替换，减少不必要的深层响应式处理。
- 代码可视化加入通用权限矩阵；词汇自测增加两个翻译模式共 33,614 种分档答对数量组合检查。

## 性能对照

同一台机器、相同构建配置的前后对照，版本说明更新前测量：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 首页入口 JavaScript | 225,235 字节 | 185,019 字节 |
| 入口文件 gzip 大小 | 84,512 字节 | 71,141 字节 |
| 128 项数组每帧比例计算的元素读取次数 | 16,384 | 128 |

入口文件减少约 17.9%，gzip 大小减少约 15.8%。这是文件大小和确定性的运算次数对照，不等于网站整体响应速度提升相同比例。数组图用空数组、负数、零和混合值核对，柱高与修改前一致。

词汇组合检查穷举的是：五个档位、每档六道题、每档答对 0–6 道，共 `7⁵ × 2 = 33,614` 种计分情况。检查分数范围、总数和单调性，不代表词库经过人群校准。权限矩阵穷举逐项授权和撤权，不声称覆盖所有权限子集。

自动化测试使用合成账号和隔离数据，AI 网络边界使用模拟响应；没有调用个人密钥、消费模型余额或发送真实短信。真实供应商可用性、公网容量和所有浏览器组合不在这轮结论内。

## 更新

本版自动新增公告已读记录表（V50），不改写已有账号、笔记和学习记录。更新前保留备份，个人配置与数据沿用原安装目录。桌面固定入口文件夹名称不变，启动文件改为 `0.15.exe`。旧标签页保存编辑后刷新即可。

交付检查结果将在安装文件实际发布并验证后补充。
