# 用户号、查找权限与手机号绑定

在 **设置 → 隐私与数据 → 用户号与查找权限** 设置用户号。它由 6–24 位英文字母或数字组成，大小写不区分，全站唯一。永久身份码仍由系统分配，不会因用户号修改而变化。修改后，旧用户号停止指向原账号，并可被其他用户使用；用户号不是登录凭证。

联系人页面支持选择查找方式：自动识别、用户号、邮箱、手机号、昵称/用户名/身份码。用户号、邮箱和手机号采用完整匹配；纯数字用户号与手机号可能相似时，请明确选择查找方式。

## 隐私规则

- 总开关关闭后，不能通过任何查找方式找到该账号，也不能直接指定用户 ID 发起新的好友申请。
- 用户号、身份码、用户名与昵称共用一个开关；邮箱和手机号分别控制，默认关闭。
- 邮箱必须与当前已验证邮箱一致；手机号必须通过短信验证。填写号码或勾选开关本身不构成验证。
- 搜索结果不返回邮箱、手机号、验证码、密码或绑定详情。姓名可以重复，请核对用户号或身份码。
- 黑名单、账号停用和使用期限限制仍生效。对外统一表现为找不到可添加用户，不说明对方是隐藏、拉黑还是停用。
- 系统管理及审核账号不会出现在好友或群邀请搜索结果中，不能通过直接请求或旧好友申请绕过限制。判定覆盖 ADMIN/CHECK/REVIEWER/MODERATOR/AUDITOR 角色，以及具有管理用户、修改权限或审核举报权限的角色或个人授权。个人开关不能解除这一限制。
- 管理后台按权限查看用户、已存在的群成员关系和官方站内信联系渠道仍按原权限执行；“不允许添加好友”不等于删除管理记录或退出现有群组。

## 手机号绑定

入口：**设置 → 账号与绑定 → 手机号绑定**。

1. 输入完整手机号和当前密码；启用双重验证的账号同时输入验证器代码或恢复码。
2. 发送短信后，输入 6 位验证码，在 5 分钟内完成验证。每个验证码最多尝试 5 次，成功后不能重放。
3. 在隐私设置中开启手机号查找。更换绑定期间，旧号码持续有效，直到新号码验证成功。
4. 解除绑定需要当前密码及已启用的双重验证，并有确认弹窗；解除后自动关闭手机号查找。

支持 `+国家区号` 格式；中国大陆 11 位手机号可自动补 `+86`。同一手机号只能绑定一个账号。界面只回显脱敏号码，验证码加密保存；注销清理会移除绑定及验证码信息。

## 部署短信服务

默认不启用短信。没有配置时，界面明确显示暂不可用，不生成可绕过验证的演示验证码，也不会发送真实短信。

部署者设置以下环境变量后，重新创建 backend 服务：

```dotenv
SMS_GATEWAY_URL=https://sms.example.com/verification
SMS_GATEWAY_TOKEN=由部署者保存的网关访问令牌
```

这是**自有短信适配网关**协议，不是某家短信供应商的直接 API 地址。适配网关需把下面的请求转换为已购买供应商的签名、短信模板和发送请求；用户不需要也不能填写网关地址或令牌。

平台向固定 HTTPS 地址发送 `POST`，带 `Authorization: Bearer …` 与 `Idempotency-Key`：

```json
{
  "phone": "+8613812345678",
  "code": "123456",
  "expiresIn": 300,
  "requestId": "每次请求的唯一标识"
}
```

网关只有在短信供应商已接受该请求时返回 2xx，拒绝或失败返回非 2xx。平台不读取、记录或展示供应商响应正文，不自动重试，不跟随重定向；地址必须解析为公网地址，禁止向内网发送验证码和令牌。

平台限制每个账号每天 5 次发送、两次发送间隔 60 秒，并保留失败或超时的额度；账号安全操作另有来源 IP 频率限制。网关还应按目标号码、来源应用和全局预算限流，并按 `Idempotency-Key` 去重，避免多账号滥发及额外费用。短信模板、签名审核、费用和真实送达验收由部署者在供应商端配置。

本地自动化测试使用模拟短信发送器，不会向上述示例号码或任何真实号码发送短信。没有配置供应商时，不能把这些测试视为真实短信送达成功。
