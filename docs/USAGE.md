# 日常使用

[← 项目首页](../README.md) · [全部文档](README.md)

登录后，右上角的「目录与账户」可以进入所有已授权功能。首页的工作目录也能直接进入笔记、背单词和实验台。

## 从工作台继续

工作台显示最近编辑的笔记、当前词书、待复习数量和实验记录。点击笔记标题接着写，点「继续学习」进入词书。「刷新概览」可手动更新进度；某个区域加载失败时可以单独重试，其余区域仍可使用。

在「目录与账户」点击页面旁的 **＋**，可将常用功能固定到顶部，最多 5 个；点击 **✓** 取消。右侧「最近访问」可返回之前使用的模块，也能清除记录。

常用入口和最近访问只保存在当前浏览器，按账号分开，不保存笔记正文或搜索关键词，也不跨设备同步。管理员收回某项权限后，对应入口会隐藏。

## 笔记与资料

1. 打开「我的笔记」，在左侧选择学习库，右侧搜索、筛选或新建笔记。
2. 使用 Markdown / HTML 编写内容，右侧查看预览。代码块可选择语言，显示对应的语法高亮。
3. 用模板、分类和复习计划整理内容；需要找回已删除的笔记时，打开左侧底部的回收站。
4. 需要 AI 时，先完成个人配置，再使用解释、润色或自测。结果由你决定是否保存。

学习中心可搜索和收藏资料，制作复习卡，切换表格、看板和月历。搜索支持空格分隔多个关键词，按相关性或更新时间排序。点击结果旁的「收藏」，以后从「我的收藏」打开；常用筛选条件可点「保存当前搜索」。

完整步骤见 [学习中心、搜索与评测](LEARNING_WORKSPACE.md) 和 [笔记整理与个人流程](PERSONAL_WORKFLOWS.md)。

## 每日背词

「背单词」顶部切换今日学习、词书、单词本和学习记录。先选一本词书，再开始练习；同一个账号的同一个单词跨词书共享进度。

开始答题后默认读一次美音，可切英音、慢速，或关闭新词自动听读。熟悉的单词可以点 **Skip**，在「单词本 → 已跳过」恢复学习。学习区的「键盘快捷操作」列出了可用按键。

需要讲解搭配、生成练习或修改造句时，使用 AI 学习助手。发送前可以预览内容，结果不会自动算作答对、掌握或复习。

词书、导入、去重、备份和恢复见 [背单词指南](VOCABULARY.md)。

## 通知与已读

收到站内信、聊天消息或群公告时，右上角提醒约 **5 秒**。鼠标移入或用键盘选中可暂停收起，关闭提醒本身不会标记已读。

| 内容 | 怎样清除未读 |
| :--- | :--- |
| 站内信 | 打开对应信件 |
| 私聊与群消息 | 打开并阅读对应会话 |
| 群公告 | 点击「我已阅读」；公告更新后会重新提醒 |

免打扰会话不弹出提醒。通知角标只计算未读消息；联系人申请、群邀请、到期复习和备份告警在「待处理事项」中保留，处理完成后消失，不计入角标。

点击「备份需要处理」可查看备份状态和恢复说明。阅读提示不会修复备份失败，需要按提示处理实际问题。

每个账号都有系统分配的唯一身份码。可按身份码查找联系人，显示名称可以重复。群资料、发言和成员管理受组内权限控制。具体操作见 [群组与站内信](GROUPS.md)。

## 外观与动态效果

「设置 → 外观」可选择鼠尾草、玫瑰、雾蓝或鸢尾主题配色，背景、文字、按钮和波纹会一起变化。每套配色支持浅色、深色和跟随系统，更改即时保存，同一浏览器里的账号各自设置。

顶部波纹按钮可暂停或开启动态效果。系统启用「减少动态效果」时自动停用；切到后台或滚出波纹区域也会暂停。笔记正文和预览区保持静止，背单词开始答题后，学习卡片内的波纹会隐藏。

## 搜索与帮助

- **Ctrl + K**：打开搜索，↑↓ 选择，Enter 打开，Esc 关闭。
- **目录与账户 → 操作文档**：查看逐步说明；在文档页按 Ctrl + K 搜索帮助条目。
- **设置**：管理个人资料、AI、使用记录、安全、绑定、隐私和外观。

配置 AI、共享记忆和本地训练见 [个人 AI](PERSONAL_AI.md)；邮箱、登录和备份见 [账户安全](ACCOUNT_AND_RECOVERY.md)。
