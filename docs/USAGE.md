# 日常使用

[← 项目首页](../README.md) · [全部文档](README.md)

登录后，右上角的「目录与账户」可以进入所有已授权功能。首页的工作目录也能直接进入笔记、背单词和实验台。

## 第一次使用，先做一件小事

已经能打开网站，就不需要重新安装项目。先注册或登录，然后在右上角 **目录与账户** 选择功能。不同账号能看到的入口可能不同，缺少入口时请联系管理员检查权限。

工作台的 **从这里开始** 提供四个入门任务。每项下面的 **怎么操作** 可以展开步骤；做完后点 **检查完成情况**。只打开页面不会被算作完成。引导可以收起，以后再展开。

| 你想做什么 | 去哪里 | 完成后怎么确认 |
| :--- | :--- | :--- |
| 记录想法、课堂内容或代码 | 我的笔记 → 新建笔记 | 显示“已保存到服务器”，重新打开仍有内容 |
| 学单词、搭配和拼写 | 背单词 → 我的词书 | 选书并答题后，“学习记录”中出现记录 |
| 阅读已有 PDF / Word | 学习中心 → 文档阅读 | 导入完成后，点击标题能看到正文 |
| 检查知识点是否记住 | 学习中心 → 复习卡 | 保存后卡片出现在列表，评分后显示下次复习时间 |

这四项都不需要 AI 密钥。第一次不必配置模型或训练环境，也不必一次用完所有功能。

### 先写一篇笔记

1. 在 **我的笔记** 点击 **新建笔记**，填写标题，例如“今天学到的三个概念”。
2. 选择学习库，或输入自己的分类名称。学习库类似文件夹；新名称会在保存后出现在左侧列表。
3. 编写格式保留 **Markdown** 即可，直接输入普通文字也可以。左边编辑，右边预览；需要代码块时再选择代码语言。
4. 写好正文后停止输入约 1.5 秒，等待 **已保存到服务器**。也可手动点击保存按钮。
5. 回到笔记列表，重新打开这篇笔记，确认内容仍在。笔记默认私密，需要让别人阅读时再主动创建分享链接。

如果显示“尚未同步”，不要直接关掉页面。保留页面重试，或先下载草稿。导出 MD / PDF / Word 是保存文件副本，与服务器上的笔记保存是两件事。

### 再完成一次词汇练习

1. 进入 **背单词 → 我的词书**，选择一本词书；返回 **今日学习**。
2. 第一次保留默认练习方式，点击 **开始学习** 或 **学习新词**。默认会自动读一次美式发音；不想自动听读可以取消勾选。
3. 看场景、理解搭配，再按照题目要求回忆并提交答案。遇到熟词可以点 **Skip**，以后在单词本恢复。
4. 打开 **学习记录** 检查答题记录。相同单词在其他词书里会接续已有进度，不用从头学。

“答过一题”“初步掌握”和“长期记住”不同。新词累计答对 4 次后进入复习；到期词可以从 **到期复习** 开始。

### 导入资料与制作复习卡

- **导入资料：** 学习中心 → 文档阅读 → 导入文档，选择 PDF 或 DOCX。处理期间在 **任务与同步** 查看进度。完成后点击文档标题阅读；扫描件可启用本地文字识别，识别结果仍需校对。自己的总结可以另存为笔记。
- **制作复习卡：** 学习中心 → 复习卡，在 **制作一张复习卡** 填写问题、答案和学科，再点 **保存复习卡**。点击列表里的问题，先回忆，再显示答案，根据实际情况评分。评分后系统会安排下次复习。

### 不明白时在哪里找说明

部分标题、统计项和配置项旁有圆形 **?**。鼠标移上去即可看简短解释；用键盘可以按 **Tab** 聚焦，按 **Esc** 收起。提示只展示说明，不会保存表单、修改学习进度或调用 AI。

需要完整步骤时，在 **操作文档 → 第一次使用：跟着做** 查阅，或在文档的 **查找与目录** 中输入关键词。中文 / EN 切换也适用于这些说明。

| 遇到的情况 | 可以先这样处理 |
| :--- | :--- |
| 按钮不能点 | 看是否正在加载、是否缺少必填内容；需要选择的词书、资料或模型是否已选好 |
| 找不到某个功能 | 确认当前账号，再请管理员检查权限；重复注册不会增加权限 |
| 导入后暂时没看到正文 | 查看“任务与同步”的状态；失败时先读错误说明，再重试 |
| 没有个人模型 | 普通学习可以继续；需要 AI 时才到“设置 → 个人 AI”保存并启用自己的配置 |
| 显示 AI 连接失败 | 模型 ID 要用模型目录里的名称，不能填写密钥 ID；接口区域应与创建密钥的平台一致 |
| 通知数字没有消失 | 关闭弹出提醒不等于已读，进入对应消息或按公告的已读操作处理 |

## 从工作台继续

工作台显示最近编辑的笔记、当前词书、待复习数量和实验记录。点击笔记标题接着写，点「继续学习」进入词书。「刷新概览」可手动更新进度；某个区域加载失败时可以单独重试，其余区域仍可使用。

在「目录与账户」点击页面旁的 **＋**，可将常用功能固定到顶部，最多 5 个；点击 **✓** 取消。右侧「最近访问」可返回之前使用的模块，也能清除记录。

常用入口和最近访问只保存在当前浏览器，按账号分开，不保存笔记正文或搜索关键词，也不跨设备同步。管理员收回某项权限后，对应入口会隐藏。

## 笔记与资料

1. 打开「我的笔记」，在左侧选择学习库，右侧搜索、筛选或新建笔记。
2. 使用 Markdown / HTML 编写内容，右侧查看预览。代码块可选择语言，显示对应的语法高亮。
3. 用模板、分类和复习计划整理内容；需要找回已删除的笔记时，打开左侧底部的回收站。
4. 需要 AI 时，先完成个人配置，再使用解释、润色或自测。结果由你决定是否保存。

学习中心可搜索和收藏资料，制作复习卡，切换表格、看板和月历。搜索支持空格分隔多个关键词，按相关性或更新时间排序。点击结果旁的「收藏」，以后从「我的收藏」打开；常用筛选条件可点「保存当前搜索」。

完整步骤见 [学习中心、搜索与评测](LEARNING_WORKSPACE.md) 和 [笔记整理与个人流程](PERSONAL_WORKFLOWS.md)。

## 每日背词

「背单词」顶部切换今日学习、词书、单词本和学习记录。先选一本词书，再开始练习；同一个账号的同一个单词跨词书共享进度。

开始答题后默认读一次美音，可切英音、慢速，或关闭新词自动听读。熟悉的单词可以点 **Skip**，在「单词本 → 已跳过」恢复学习。学习区的「键盘快捷操作」列出了可用按键。

需要讲解搭配、生成练习或修改造句时，使用 AI 学习助手。发送前可以预览内容，结果不会自动算作答对、掌握或复习。

词书、导入、去重、备份和恢复见 [背单词指南](VOCABULARY.md)。

## 通知与已读

收到站内信、聊天消息或群公告时，右上角提醒约 **5 秒**。鼠标移入或用键盘选中可暂停收起，关闭提醒本身不会标记已读。

| 内容 | 怎样清除未读 |
| :--- | :--- |
| 站内信 | 打开对应信件 |
| 私聊与群消息 | 打开并阅读对应会话 |
| 群公告 | 点击「我已阅读」；公告更新后会重新提醒 |

免打扰会话不弹出提醒。通知角标只计算未读消息；联系人申请、群邀请、到期复习和备份告警在「待处理事项」中保留，处理完成后消失，不计入角标。

点击「备份需要处理」可查看备份状态和恢复说明。阅读提示不会修复备份失败，需要按提示处理实际问题。

每个账号都有系统分配的唯一身份码。可按身份码查找联系人，显示名称可以重复。群资料、发言和成员管理受组内权限控制。具体操作见 [群组与站内信](GROUPS.md)。

## 外观与动态效果

「设置 → 外观」可选择鼠尾草、玫瑰、雾蓝或鸢尾主题配色，背景、文字、按钮和波纹会一起变化。每套配色支持浅色、深色和跟随系统，更改即时保存，同一浏览器里的账号各自设置。

页头的波纹缓慢流动，工作台学习卡片、当前词书、笔记侧栏、知识库、群组、站内信和个人设置有局部涟漪。点击按钮、导航或主题配色时，会从点击处扩散出两层水纹；使用键盘操作时，从控件中心扩散。

桌面鼠标经过快捷卡片、词书或主题配色时，会出现随位置移动的光泽；经过水纹区域时，波纹轻微偏移。按钮的点击位置保持稳定，输入、拖选文字时不触发这些效果。首页「学习」预览可点击查看搭配用法、切换下一题，这里的体验不计入账号学习记录。

顶部波纹按钮可暂停或开启动态效果。系统启用「减少动态效果」时自动停用；切到后台或滚出波纹区域也会暂停。笔记正文和预览区保持静止，背单词开始答题后，学习卡片内的波纹会隐藏。

## 搜索与帮助

- **Ctrl + K**：打开搜索，↑↓ 选择，Enter 打开，Esc 关闭。
- **目录与账户 → 操作文档**：查看逐步说明；在文档页按 Ctrl + K 搜索帮助条目。
- **设置**：管理个人资料、AI、使用记录、安全、绑定、隐私和外观。

配置 AI、共享记忆和本地训练见 [个人 AI](PERSONAL_AI.md)；邮箱、登录和备份见 [账户安全](ACCOUNT_AND_RECOVERY.md)。
