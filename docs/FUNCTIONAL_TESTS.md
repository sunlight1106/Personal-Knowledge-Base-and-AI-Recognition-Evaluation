# 功能验收

这份清单用于发版前回归。测试覆盖常用流程、权限组合和失败后的恢复，不代表枚举了所有输入，也不等同于生产环境安全审计。最近一次实际结果见 [验证记录](VALIDATION.md)。

## 检查范围

| 模块 | 正常操作 | 异常与权限边界 |
| --- | --- | --- |
| 账号 | 登录、注册、切换账号、会话管理、绑定、注销与恢复 | 失效凭证、到期账号、撤销会话、重复请求、旧账号的延迟响应 |
| 管理 | 用户、角色、个人权限覆盖、统计、审核、处罚与申诉 | 单项授权和拒绝、最后一位管理员保护、并发修改、处罚到期 |
| 笔记与知识库 | 新建、编辑、目录、版本、检索、导出、分享、回收站 | 跨用户访问、过期分享、并发编辑、恶意 HTML、代码高亮与路由切换 |
| 词汇与学习 | 词书、导入、学习、复习、Skip、备份、统计、计划 | 重复单词共享进度、重复答题、日期边界、版本冲突、离线队列恢复 |
| 联系人与群组 | 搜索、邀请、接受、拒绝、私聊、群消息、附件、公告、已读 | 黑名单、退群、只读成员、撤回权限、过期邀请、跨群与跨账号访问 |
| 文档与阅读 | 上传、解析、扫描页 OCR、原页查看、校对、摘录 | 格式与大小限制、重复上传、任务归属、取消、过期任务与校对冲突 |
| AI 与实验 | 配置、发送预览、诊断、个人记忆、识别、结果保存、训练 | 私有数据隔离、接口地址限制、流式输出中断、预算与配额；远程响应使用合成服务 |
| 文件与账单 | 文件读取、实验记录、下载、预算、余额 | 文件归属、恶意路径、重复扣费、并发余额修改、请求大小与限流 |
| 部署与恢复 | 启动检测、迁移、加密备份、恢复校验 | 同时启动、旧版升级、现有数据保护、错误密码、损坏备份、越界路径 |

界面检查同时覆盖弹窗、键盘操作、重复提交、取消、空列表、错误提示、切换页面和切换账号。真实浏览器另外检查桌面页面加载、主要内容区、横向溢出、脚本错误和接口错误。

## 本地运行

在项目根目录执行，需要 JDK 17、Node.js 22、Python 3.10+。FFmpeg 用于视频处理测试。

```sh
npm run test:unit --prefix cle
npm run test:ui --prefix cle
npm run build --prefix cle
```

后端：Windows 使用 `.\mvnw.cmd -B verify`；Linux 使用 `./mvnw -B verify`。

数据库专项需要 Docker：

```sh
python scripts/tests/run-mysql-contracts.py
```

脚本创建独立 MySQL 容器，使用随机凭证和随机数据库；不读取项目 `.env`，不连接业务数据库。结束时删除该临时容器及其数据。可以用 `--tests 类名` 复跑指定检查。Java 报告在 `target/surefire-reports/`；报告可能含合成请求内容，不要把自己的真实密钥作为测试数据。

Linux 备份检查：

```sh
python -m pip install -r scripts/backup/requirements.txt
python -m unittest discover -s scripts/backup -p 'test_*.py' -v
```

POSIX 文件权限用例必须在 Linux 环境执行。Windows 的跳过项不能算作通过。完整数据库与文件恢复演练另见 [备份说明](../scripts/backup/README.md)。

## 如何判断通过

- 看执行数、失败数和跳过数，不能只看构建成功。MySQL、FFmpeg 或恢复环境缺失时，一部分用例会跳过。
- 发现问题后保留失败原因，修复后重跑相关用例；不要只删除失败断言。
- 页面能打开只说明加载检查通过，写入、并发与隔离仍需对应的接口和交互测试。
- 真实邮件投递、供应商计费调用、公网 TLS、跨设备同步和长期高负载，需要在配置相应服务后单独验收。

GitHub 自动检查包含前后端回归、MySQL 专项、启动脚本、备份安全与训练模块；完整恢复由独立的 recovery 工作流执行。
