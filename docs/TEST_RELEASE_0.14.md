# 0.14 测试版

这次更新补充 Java 主类与辅助类执行，并处理网页更新后，已打开的标签页继续显示旧界面的问题。

## 使用变化

- Java 可以直接写 `public class main` 或 `public class Main`，入口填 `main`，无命令行参数时填 `[]`。
- 非 public 辅助类可以放在同一份代码中。支持构造方法、字段、实例方法、静态成员和 `this`，回放中可查看对象字段。
- 多个类有同名静态方法时，填写 `Helper.sum` 一类的入口，避免选错方法。
- 页面检测到新构建后会提示刷新。先保存编辑或完成答题，再点击「刷新使用新版」；不会自动清空正在做的事。
- 词汇量主结果沿用 0.13 的单一预估词数。升级前已经打开的旧页面，需要手动刷新一次才能加载这次更新。

## 支持边界

Java 仍运行在受限教学解释器中。继承、接口、泛型、内部类、方法重载、外部库和系统调用暂不支持；构造方法可按参数个数区分。跨方法调用、对象操作的复杂度没有可靠推导时会明确标注，执行步骤和次数正常记录。

版本不修改用户数据结构。升级保留账号、学习进度、笔记和个人配置。部署前备份原数据；桌面固定入口目录名称不变，启动文件为 `0.14.exe`。

## 验证范围

本地代码执行测试覆盖四种语言回归、Java 多类与对象、私有成员访问、循环引用、对象数量与递归限制；后端检查入口验证与用户记录隔离。前端检查旧版提醒、离线失败、答题保护及对象回放。具体发布与桌面核验结果在完成后补充。

这些验证不代表完整 Java 语言兼容，也不代表词汇自测已经过人群标定。

## 安装与更新

从 [v0.14 发布页](https://github.com/sunlight1106/Personal-Knowledge-Base-and-AI-Recognition-Evaluation/releases/tag/v0.14) 下载 `0.14.exe`，或完整解压 Windows 包。启动 Docker Desktop（Linux x64 容器）后运行新版启动器。

先[备份数据](COMPOSE_BACKUP.md)，关闭旧启动器，再打开新版；不要同时运行多个版本的启动器。首次准备需要下载配套文件，后续复用本地镜像。停止服务和故障处理见[桌面安装说明](TEST_RELEASE_0.11.md)。发布页附 SHA256SUMS；安装目录的 `.env` 含个人配置与初始管理员凭据，不要分享。
