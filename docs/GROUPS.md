# 群组协作与站内信

群组适合围绕论文、项目或实验交流。它沿用已有工作空间，升级后不用重新建立原来的组。

## 建群并邀请成员

1. 登录后打开顶部「目录与账户 → 群组协作」。
2. 研究员点击「新建群组」，输入名称并创建。创建者成为群主；可创建多个群组。
3. 选择群组，展开「成员与权限」。
4. 在「邀请成员」输入姓名、用户名或唯一身份码，从下拉结果中选择账号，再选择普通成员或只读成员并发送邀请。同名用户用身份码区分，结果支持分页；对方同意后才会加入。需要群管理员时，由群主在对方入群后调整角色。
5. 在会话下方输入内容，点击「发送到群组」。分享资料可选择附件；只有附件时会自动添加“分享资料”说明。

进入群组需要 `group:use`，收发群消息和站内信需要 `message:read`，建群还需要 `workspace:manage`，研究员默认拥有。管理员可在角色或单独用户设置中关闭这些功能。进入功能后仍检查具体群的成员权限，平台管理员可以查看和协助管理所有群组。管理步骤见 [管理员和用户权限](ADMINISTRATION.md)。

## 修改、退出、归档和解散在哪里

选中左侧群组后，群名下方就是管理区，不需要再展开两层菜单。

| 想做什么 | 操作入口 | 操作结果 |
| --- | --- | --- |
| 修改群名、邀请或移除成员、调整群角色 | **成员与权限** | 只影响当前群组；群管理员不能提升自己或修改群主 |
| 暂停一个群组 | **群组管理 → 归档群组** | 历史可读，停止发言和成员修改；群主可点 **恢复群组** 重新开放 |
| 把群交给别人 | **群组管理 → 转让群主** | 选择现有成员并输入当前密码；原群主成为群管理员 |
| 自己离开 | **退出群组** | 确认后失去本群消息和资料的访问权；群主需先转让或解散 |
| 结束整个群组 | **群组管理 → 解散群组** | 输入群组全名和当前密码确认；其他成员被移除，不能恢复成活跃群 |
| 看待处理的加入申请或举报 | **申请、邀请与举报** | 数字表示待处理事项；邀请需要对方同意 |

**解散不是清空所有历史。** 群主保留只读历史，平台管理员仍可按权限审核。成员退出与解散也不会删除对方已经下载的文件。当前没有一键永久擦除群历史的功能。

左侧可按 **进行中 / 已归档 / 已解散** 筛选，也可以输入群名或群组编号。只读成员和普通成员不会看到群主的转让、归档、解散按钮。即使手动请求接口，服务器也会重新检查权限。

## 讨论、回复和资料

- 在某条消息右上角点击「回复」，输入内容后发送；回复会记录原消息关系。
- 每条消息最多 5 个附件，每个不超过 20 MB，支持类型由已有内容检查规则决定。伪造扩展名、可执行内容和病毒扫描不通过的文件会被拒绝。
- 点击资料名称下载。服务器每次检查当前群成员资格和阅读权限，附件没有公开永久地址。
- 新消息会自动刷新；连接中断时会重连。每次加载 50 条，点击「查看更早的消息」加载历史。也可以手动刷新。
- 成员加入后可以查看本群历史消息与资料；不适合让新成员只看加入后的消息。

## 整理会话

- **置顶会话**：把常用群放在列表前面，只影响自己的账号。
- **未读**：未打开群组的新消息显示数量；打开会话后标记已读。自己发送的消息不算未读。
- **免打扰**：保留会话和未读数量，但不在顶部通知菜单提醒。本设置会保存到账号中。
- **短暂提醒**：新消息和公告在右上角显示约 5 秒；鼠标移入或键盘聚焦时暂停收起。点击可进入对应会话，关闭弹窗不等于已读。通知中心仍保留待阅读的内容。
- **公告已读**：看完公告后点击「我已阅读」。已读记录只影响自己的账号；管理员修改公告后会再次提醒，单独调整置顶消息不会把旧公告变成未读。
- **群公告**：有群设置权限的群主或管理员可以编辑，所有有阅读权限的成员可见。其他人已修改时会提示刷新，避免覆盖。
- **置顶消息**：在消息右上角点击「置顶」，重要内容显示在会话上方；可取消。
- **查找消息**：搜索本群的文字，支持加载更多结果；搜索不到其他群组。附件仍在原会话下载。
- **发送**：支持回复、资料附件和 Ctrl + Enter；发送前可移除选错的附件。

## 群角色与平台角色是两回事

| 群角色 | 读取 / 下载 | 讨论 / 发资料 | 成员管理 | 提升群管理员 |
| --- | --- | --- | --- | --- |
| 群主 | 可以 | 可以 | 可以 | 可以 |
| 群管理员 | 可以 | 可以 | 可添加、调整、移除普通成员和只读成员 | 不可以 |
| 成员 | 可以 | 可以 | 不可以 | 不可以 |
| 只读成员 | 可以 | 不可以 | 不可以 | 不可以 |

群角色只影响本群，不能据此访问平台用户管理、角色配置或其他群组。群管理员不能修改群主或其他群管理员。已有自定义群权限可以收窄权限，但不能超过对应群角色的范围。

有成员管理权限的用户可以分页搜索邀请对象。搜索尊重账号的可被发现设置、黑名单和使用期限；普通成员不能读取邀请目录。只读成员在成员列表中只能看见自己。旧的成员修改接口只调整已有成员，不能绕过入群确认。

## 邀请与申请状态

在群组页展开 **邀请与加入申请**，可以查看自己发出的记录及待处理、已接受、已拒绝、已取消、已过期状态。待处理记录可点 **撤回**。同一群组与同一对象再次邀请时更新该条记录，这里不是不可修改的完整审计历史。

## 站内信与联系管理员

1. 打开「目录与账户 → 站内信箱」。
2. 点击「联系管理员 · 姓名」，或点击「写信」选择收件人。
3. 输入主题、正文，按需添加附件，点击「发送消息」。
4. 收件人在收件箱打开消息，点击「回复这封信」即可回复。

拥有站内信权限的用户可以联系平台管理员。管理员可以联系启用且未到期的账号；双方拉黑时也不能发信。普通用户还可以联系已接受的联系人，或符合群内读写权限的同组成员，对应的联系人、群组功能权限必须仍然有效。停用、到期账号和本人不在可选收件人中。每封信最多 20 位收件人。

群消息在群组页面查看，私人站内信在收件箱 / 已发送查看。私人站内信正文、附件仅限发送者和收件人，平台管理员也不能直接读取别人的信；举报后，审核者通过举报证据处理。收件人信息不包含邮箱。历史私信仍按原参与者的访问关系保留，不因退群而删除。

勾选站内信列表中的消息，可以批量 **标为已读、归档、移入回收站**。在归档和回收站中点 **恢复**，消息会回到原来的收件或发件分类。整理和已读只影响当前账号，不会删除其他收件人的副本；回收站目前不提供永久擦除整封共享消息。

群组权限收回后，即使保留原登录凭证、消息 ID 或下载地址，也不能继续读取或发送群消息。接受旧邀请时，服务器再次检查邀请人的账号、当前群组权限、成员管理权限和双方黑名单；邀请人已离组或权限失效时不能继续入群，仍可拒绝邀请。

## 退出、移除与权限收回

- 非群主成员可点击「退出群组」；群主不能直接退出自己的群组。
- 群主或有相应权限的群管理员可移除成员。退出或移除后，该用户不能继续从服务器读取群消息、发送消息或使用旧群附件链接。
- 服务器校验群组、消息和附件的对应关系；改请求里的群 ID、消息 ID 或附件 ID 不会得到另一群组的访问权。
- 群消息不会出现在私人「已发送」列表，原发件人退群后也不能借此继续阅读群历史。
- 已经下载到成员电脑或复制出去的内容无法撤回。
