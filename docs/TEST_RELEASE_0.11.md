# 0.11 测试版

本次更新包含账号登录保护、唯一用户号与联系隐私、黑名单改进、资料问答批量选择和 AI 错误恢复。完整变化见 [更新日志](../CHANGELOG.md)。

## 安装和升级

1. 安装并启动 Docker Desktop，使用 Linux x64 容器。
2. 在 [v0.11 发布页](https://github.com/sunlight1106/Personal-Knowledge-Base-and-AI-Recognition-Evaluation/releases/tag/v0.11) 下载 Windows 压缩包，完整解压后运行 `0.11.exe`。单独下载 EXE 时，启动器会获取并校验配套运行文件。
3. 首次准备需要网络和磁盘空间，完成后自动打开网站；日常启动复用已有镜像与数据。
4. 首次管理员账号为 `admin`，初始密码保存在安装目录 `.env` 的 `BOOTSTRAP_ADMIN_PASSWORD`。在启动窗口点击「打开安装目录」可找到它。不要分享此文件。

已有用户先做 [完整备份](COMPOSE_BACKUP.md)，再关闭旧启动窗口，运行 `0.11.exe`。
升级沿用 `%LOCALAPPDATA%\PKB-AI\0.1`、原配置和数据卷；目录名仅是兼容路径。包含 V47/V48 数据库迁移，不能直接运行旧 EXE 降级。
源码版与安装版的数据相互独立，安装包不会自动搬运另一套安装的笔记或账号。

## 使用条件

- 普通笔记、词汇学习和代码可视化无需个人 AI 密钥。外部 AI 使用本人配置，模型、额度与费用由供应商决定；发送前仍需预览并确认。
- 手机号必须验证归属才可用于查找。未配置短信服务时显示不可用；不会把输入过的号码直接当作已绑定。
- 资料问答取消 8 份数量限制，但单次模型上下文仍有限；长资料会提取并展示实际发送片段，无法容纳时明确提示。
- 0.x 仍是测试版。项目测试覆盖主要流程、权限边界和异常处理，不代表所有输入和操作顺序都已穷举，也不代表所有供应商已真实调用。

发布页的 `SHA256SUMS` 用于核对下载文件。遇到问题时提供版本、操作步骤和不含密钥的错误信息；详细证据见 [验证记录](VALIDATION.md)。
