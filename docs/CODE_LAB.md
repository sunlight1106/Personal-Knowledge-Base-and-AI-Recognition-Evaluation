# 代码可视化

入口：登录后打开导航菜单，选择 **代码可视化**。本地地址为 `/app/code-lab`。

不需要 AI 密钥。代码在本次部署的独立解释服务中处理，不发送给外部模型供应商。每个人只能查看和删除自己的执行记录。

## 第一次使用

1. 在「示例」里选择 Python、C、Java 或 JavaScript，点击「载入」。
2. 先保留示例的入口 `sort` 和参数，点击「运行并可视化」。
3. 点击「播放」，观察数组里的数字交换。底色变化表示变量相对上一步发生了改变。
4. 拖动时间轴或点击左右箭头，可以返回任意一步。调用栈里的按钮可以切换正在查看的函数层。
5. 下方源码左侧的数字是行号，旁边的小数字是该行记录的事件数。点击行号，再选择第几次执行，可以检查循环中间的某一轮。
6. 切换「概览」，查看循环迭代、函数调用、各行记录次数和复杂度估算。

## 运行自己的函数

有 `main` 的 C / Java 代码会自动寻找入口。没有 `main` 也可以直接填写函数名称。Java 方法片段可以不写外层 class，但需声明 `static`。

例如：

```java
static int sum(int[] values) {
    int total = 0;
    for (int i = 0; i < values.length; i++) {
        total += values[i];
    }
    return total;
}
```

「入口函数」填写 `sum`，「参数（JSON）」填写 `[[3, 1, 2]]`。运行后返回值应为 `6`。

最外层数组对应参数列表：

| 函数参数 | JSON 输入 |
| --- | --- |
| 一个整数 n | `[5]` |
| 两个整数 a、b | `[3, 8]` |
| 一个整数数组 | `[[5, 2, 8, 1]]` |
| 一个数组和它的长度 | `[[5, 2, 8, 1], 4]` |
| 没有参数 | `[]` |

Python / JavaScript 的入口留空时，从顶层语句执行。指定函数时只运行这个函数，所需数据应作为参数传入；不会先执行顶层初始化。依赖全局变量的片段需要先改为参数形式。

## 支持到什么程度

这是**受限教学解释器**，支持四种语言的常见算法子集，不是完整编译器或在线开发环境。支持变量、赋值、算术、条件、for / while、break / continue、函数、递归、数组索引及常用输出。Python 支持 `range`、`len`、列表和交换赋值；JavaScript 使用 `let` / `const`。

C / Java 以有符号 32 位整数、布尔和一维数组算法为主；整数溢出会停止，Java 溢出也不会按原生 JVM 回绕。C 未初始化读取和数组越界会报错。Java 暂不支持实例对象。Python 整数限制为 256 位，JavaScript 整数限制在安全整数范围内。不支持的语法或调用会给出行号。

以下内容暂不支持：指针、动态内存、类实例、泛型、导入库、闭包、异常处理、文件、网络、系统命令、交互式输入。不要把完整工程直接粘贴进来；先提取要观察的算法函数。

| 限制 | 上限 |
| --- | --- |
| 源码 | 400 行、16 KB |
| 参数 | 最外层 16 项、JSON 文本 8 KB |
| 数组 / 列表 | 128 项 |
| 调用栈 | 24 层，包含顶层帧 |
| 回放事件 | 1,000 步 |
| 内部求值 | 20,000 次 |
| 输出 | 8,000 字符 |
| 解释执行时间 | 约 3 秒；独立进程硬超时 5 秒 |
| 保存记录 | 每账号最近 20 次 |

超限后显示「达到限制」。已有步骤仍可查看，但不能把部分执行当作完整结果。执行环境未启动时会提示不可用，不会伪造结果。

## 次数和复杂度怎么看

- **记录步骤**：语句完成、条件判断、循环更新、函数进入和返回等事件。同一源码行可能包含多个事件。
- **循环迭代**：实际进入循环体的次数。条件判断次数可能比循环体多一次。
- **函数调用**：用户定义函数的调用次数，不包含内置输出函数。
- **内部求值**：解释器处理的表达式和语句数量，不是 CPU 指令数，也不是原生程序耗时。
- **复杂度估算**：只对能识别的简单 for 结构给出上界，并写明假设。遇到递归、while、动态边界等返回「暂无法可靠推断」。不会根据一次执行的步数断言 O(n)。当前不静态推断空间复杂度。

## 保存、导出和删除

每次运行会自动保存源码、参数、输出与回放，最多保留最近 20 条。旧记录会自动清理。「导出回放」下载 JSON；「导出当前图像」下载当前调用栈、变量与数组的 SVG 图，可以在浏览器打开。JSON 用于留存和自行分析，当前没有回放文件导入功能。

记录可在「我的执行记录」里删除；删除不可撤销。账号数据导出包含这些记录，永久注销账号时一并删除。管理员能控制使用权限，但不能越过记录的所有权限制读取其他用户源码。

## 部署与权限

部署脚本会生成独立的 `CODE_LAB_SERVICE_TOKEN` 并启动 `code-lab` 服务。新安装执行 `deploy.ps1` / `deploy.sh`；更新已有安装执行 `deploy.ps1 -Build` / `deploy.sh --build`。升级增加服务时，第一次会补齐缺失组件。

容器不对宿主机发布端口，不挂载项目数据、数据库或 Docker 通信文件；以非 root 身份运行，根目录只读，限制 CPU、内存和进程数。每次执行使用新进程，解释器没有用户可调用的文件、网络或命令接口。它解释语法树，不使用 `eval` / `exec` 执行用户源码。

管理员在角色或用户权限中控制 `code-lab:use`；审核处罚也可单独限制「代码执行」。标准研究员、查看者角色升级后获得入口，自定义角色需要管理员明确授予。代码服务不可用不会阻止笔记、背单词等页面启动。

执行服务最多同时处理两次请求，忙碌时立即提示重试；每个 API 实例也限制同一账号一次在途执行。页面离开会停止播放与等待，已经开始的服务端计算仍受硬超时限制，结果可能已保存，可回来刷新历史查看。
