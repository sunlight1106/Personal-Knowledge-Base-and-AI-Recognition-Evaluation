# 学习安排、阅读摘录与后台任务

[← 使用文档](README.md)

## 按可用时间安排学习

打开「学习统计 → 今天的学习安排」，点击「调整时间」。设置每天可用的分钟数，以及希望用几天分摊积压复习。

页面依次安排到期词汇、复习卡和隔日薄弱项，再使用剩余时间安排新词与阅读。每项都可以直接进入对应页面。时间采用学习统计中的活跃时长，耗时估计会参考最近一周的作答速度；它不是严格倒计时，也不证明学习效果。达到目标后仍可继续学习。

分摊积压不会修改单词原来的到期日。休息日会提示可以自愿练习。计划只保存到当前账户，两个页面同时修改时，后保存的旧版本会被拦截。

## 让薄弱项进入下一次练习

「背单词 → 学习记录 → 隔日再检查」列出已经到期的拼写、听写、释义和搭配练习，点击「练这一项」直接开始。

新答错的分项从次日开始跟进。提示后的正确、刚看完答案的重复，以及同一天的重复提交，都不抵消这项薄弱记录。不同日期独立通过两次后结束跟进；第一次通过后，三天后再检查。再次答错则重新安排。原有的 FSRS 词汇进度继续保留。

这份跟进队列从更新后的实际作答开始积累，不根据旧的汇总数据推测哪一天曾独立通过。

## 读到哪里，整理到哪里

在「学习中心 → 文档阅读」的正文，或已保存笔记的预览里选中文字。下方会出现学习工具：

- **查词、听读**：查询本地词库的释义、音标与用法，默认美音朗读。输入的词需要来自选中的原句。
- **加入单词本**：收藏单词，同时保留原句和来源，跨词书仍使用原来的学习进度。
- **制作复习卡**：把选区作为答案，生成一张可编辑的问题卡。可以去「复习卡」调整问题。
- **保存摘录**：建立一篇带来源链接的笔记。

「阅读摘录」展示最近 100 条原句记录。移除摘录不会删除已经制作的笔记、复习卡或单词收藏。单个选区最多 4,000 字，每个账户最多 5,000 条摘录。笔记有未保存修改时，先保存再摘录，避免标错来源。

## 导入扫描版 PDF

1. 打开「学习中心 → 文档阅读」，保留勾选「自动识别扫描页」。
2. 上传 PDF 或 `.docx`，看到已加入后台任务后可以离开页面。
3. 在「任务与同步」查看进度，完成后点击「打开文档」。
4. 有识别错误时，点击「对照原页并校对」，修改右侧文字并保存。

Docker 镜像包含 Tesseract 的中文、英文识别环境，扫描页在本地处理，不调用外部模型。单份文件最多 10 MB、300 页，一次最多识别 60 个扫描页。文字过少的 PDF 页面会尝试 OCR；复杂表格、手写和特殊排版需要人工核对，不承诺保留原版式。Word 提取文字，暂不识别其中嵌入图片里的文字。

校对修改提取结果，原文件保留。已有摘录保留当时的文本，搜索读取最新校对内容。

## 查询后台操作

「学习中心 → 任务与同步」集中显示文档导入、OCR、词书导入、词汇备份恢复、资料导出、离线词汇同步和本地训练。

文档任务支持取消与重试，最多同时排队或处理三份，每项最多尝试三次。重启导致处理中断时，任务会在处理租约过期后标为未完成，可以重试。重复上传同一文档会定位到已有文档，不创建第二份正文。

导出完成表示服务器已经生成响应，需要自行确认浏览器下载成功。离线笔记冲突仍在离线页面处理。普通请求失败后应回原页面确认结果，再重试；任务中心不会自动重发消息、重复同步或重新调用付费模型。

导入、导出和同步操作记录保留 90 天。文档任务可手动移除；未被资料引用的暂存文件会进入清理队列，已成功导入的文档保留。

## 用自然语句找资料

在资料搜索的排序选项中选择「自然语句（本地扩展）」。例如输入「之前那个解决过拟合的方法」，可以检索包含 `dropout`、`regularization` 等相关表达的资料。

这个模式使用本地概念词表和相关性排序，覆盖常见的英语学习、计算机、数学与 AI 概念，不会向供应商发送查询或笔记。它不是通用向量语义模型；遇到未收录的说法，可以换关键词搜索。检索先检查当前权限，删除的资料、别人私有的笔记和无权访问的群资料不会进入结果。
